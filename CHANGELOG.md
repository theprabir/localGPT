# Changelog

## 0.1.1

- Fixed Enter-to-send: Alpine suppresses key handlers when a non-key modifier (`.exact`) is combined with a key modifier, so the composer now handles Enter in JS — Enter sends, Shift+Enter inserts a newline
- Stop generation is reachable again: the composer button now switches to a stop action while streaming instead of being disabled
- Added interface font choices (Default / Lato / EB Garamond) in Settings; fonts are vendored locally as woff2 (`app/static/fonts/`, generated by `scripts/download_fonts.py`) and applied app-wide through a single `--font-ui` variable, with code blocks kept monospace
- Settings: removed the redundant header text link and the theme popup dialog; the sidebar gear icon now links to the `/settings` page, which got a balanced two-column desktop layout plus a font picker
- Fixed chat layout: the page no longer scrolls vertically, the chat panel scrolls internally, and the composer stays pinned when messages pile up
- Conversation history is grouped by day (Today / Yesterday / date)
- Empty state now shows the theme-correct wordmark (`logo_text_light` in light theme, `logo_text_dark` in dark theme), fixing a broken `logo_text_white.png` reference
- Escape closes the mobile sidebar drawer and image viewer
- Chatbox icons are vertically centred and the composer shrinks back to one line after sending
- Slim, rounded, theme-aware scrollbars
- Fixed SSE parsing of chunks containing colons (streaming previously produced no output)

- Fixed Alpine.js component wiring: templates reference `localgpt.*` components, now exposed on `window` before Alpine initializes, so the chat UI hydrates correctly
- Mobile layout: hamburger toggle with off-canvas sidebar and backdrop below 900px
- Chat messages and image attachments are persisted before the model-readiness check, so history survives when the VLM is offline
- Uploaded images are stored via `POST /api/upload` and re-displayed in conversation history
- Fixed root `/health` returning `null` CPU/memory values (FastAPI Depends placeholders were passed directly)
- Added MIT LICENSE (Prabir kumar Das)
- Added `.gitignore` excluding model GGUF files, local data, and `AGENTS.md`
- Integrated brand icons into the UI (favicon, sidebar logo, empty-state logo)
- Added `model_download.py`: one-time model downloader that creates `.env` from `.env.example` with `VLM_MODEL` and `VLM_MODEL_PATH` pre-filled
- Updated README first-run and project structure sections
- Removed internal developer notes from documentation
