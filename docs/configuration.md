# Configuration

LocalGPT is configured via environment variables and `.env`. Prefix all variables with `LOCALGPT_`.

Key variables:

- `LOCALGPT_HOST`, `LOCALGPT_PORT`
- `LOCALGPT_LLAMA_SERVER_URL`
- `LOCALGPT_VLM_MODEL`
- `LOCALGPT_VLM_MODEL_PATH`
- `LOCALGPT_VLM_MAX_CONTEXT_TOKENS`
- `LOCALGPT_IMAGE_MODEL`
- `LOCALGPT_MAX_IMAGE_SIZE`
- `LOCALGPT_IMAGE_STEPS`
- `LOCALGPT_LOG_LEVEL`

See `.env.example` for full defaults.
