# Image Generation

Image generation is a Phase 2 feature. The Phase 1 foundation includes:

- Configuration surface for image model, size, and steps
- Generated image and job status database schema
- Image service interface with job creation and status updates
- Endpoints for upload, generated image serving, and image status

Default generation targets:

- 512×512
- Low step counts
- CPU-optimized pipeline

This document will be expanded when the image engine is integrated.
